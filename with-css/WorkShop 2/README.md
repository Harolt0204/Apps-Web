# Workshop 2 - Website with HTML and CSS

## Objective
This project corresponds to Workshop 2 of the Web Applications course (Semester II 2026). The main objective is to modify and enhance the website created in Workshop 1 by adding Cascading Style Sheets (CSS) to improve the layout, display, and overall visual design of the content.

## What was done?
1. **Directory Structure Reorganization**: Copied the previous HTML structure and adapted it to a new project structure including a dedicated `css/` directory.
2. **CSS Implementation**: 
   - Created a main `style.css` file to handle global styles (fonts, margins, background colors).
   - Improved the header and navigation bar design, removing default link styles and adding hover effects.
   - Styled forms in the contact page to have a cleaner layout, rounded inputs, and focused states for better user experience.
   - Enhanced the presentation of tables, main content containers, and images.
3. **HTML Updates**: Linked all HTML pages inside the `pages/` directory and the main `index.html` to the newly created `style.css` file.

## Structure
- `index.html`: Main home page.
- `pages/`: Contains all other internal pages (courses, schedule, contact, hobbies, clubs).
- `images/`: Stores all the images used across the website.
- `css/`: Contains the stylesheets (`style.css`).
